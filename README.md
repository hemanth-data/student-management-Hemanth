## Project Description

The Student Management System is a frontend web application developed to manage student information through a simple, responsive, and user-friendly dashboard.

The application provides student login, dashboard statistics, student management, search, filtering, sorting, profile, settings, and logout functionality.

## Features Implemented

### 1. Student Login

- Student username and password login
- Login validation
- Dashboard access after successful login
- Logout functionality
- Login session using LocalStorage

### 2. Dashboard

- Total number of students
- Department-wise student count
- Year-wise summary
- Quick access cards
- Interactive dashboard sections
- Responsive dashboard design

### 3. Student List

- Display student information in a table
- Search students by name
- Search students by register number
- Filter by department
- Filter by year
- Sort by student name
- Sort by register number
- Edit student details
- Delete student details
- Delete confirmation

### 4. Add Student

The application allows users to add new students with:

- Register Number
- Student Name
- Email
- Phone Number
- Department
- Year
- Semester

### 5. Form Validation

- Required field validation
- Email validation
- Phone number validation
- Duplicate register number validation
- Year and semester validation
- Meaningful error messages

### 6. Student Profile

- Student information
- Username
- User role
- Account status

### 7. Settings

- Account information
- Dashboard settings
- Logout option

## How to Run the Application

Using Visual Studio Code

- Download or clone the GitHub repository.

- Open the project folder in Visual Studio Code.

- Install the Live Server extension.

- Right-click index.html.

- Select Open with Live Server.

- The application will open in the browser.

- Enter the login details.

- Click Login.

- The Student Dashboard will open.

## Using a Browser

- Open the project folder.

- Open index.html.

- Enter the login details.

- Click Login.

- The dashboard will be displayed.
